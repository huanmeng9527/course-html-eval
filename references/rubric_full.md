# 10 维评分 Rubric 完整定义（v2.4 加入 learnability + flow）

每个维度的 1~5 分锚点定义，供 LLM prompt 和人工标注对齐用。

## 1. accuracy 事实准确性

- **5** 概念定义、公式、定理全部正确；引用规范；无过时信息
- **4** 主体正确，有 1~2 处小瑕疵但不影响理解
- **3** 整体可读但有 2~3 处需要核实的地方
- **2** 有明显概念混淆（如把 sigmoid 写成 softmax）
- **1** 核心概念错误，可能误导学习者

## 2. coverage 知识覆盖度

- **5** 覆盖该主题的所有关键概念 + 必要的延伸
- **4** 覆盖主要概念，缺失 1~2 个非关键点
- **3** 覆盖核心概念但遗漏重要应用场景
- **2** 多个重要概念缺失
- **1** 内容严重不足或偏离主题

## 3. structure 结构清晰度

- **5** 章节组织完美，层次分明，过渡自然
- **4** 结构清晰，偶有小跳跃
- **3** 结构可读但组织略混乱
- **2** 结构混乱，章节顺序不合理
- **1** 无清晰结构，流水账式叙述

## 4. readability 可读性

- **5** 语言流畅，术语解释到位，无长难句
- **4** 易读，少量术语需要查
- **3** 大部分可读，部分段落需要重读
- **2** 多处长难句，术语堆砌
- **1** 难以阅读

## 5. pedagogy 教学设计（v2.4 权重 0.15 ↓）

- **5** 教科书级设计：先直觉后形式，有类比，有循序渐进的小步练习
- **4** 教学路径合理，有少量类比或例子
- **3** 教学逻辑成立，但缺类比或例子
- **2** 直接堆定义，缺少引导
- **1** 没有教学设计，纯陈述

## 6. visualization 可视化

- **5** 图文并茂，所有抽象概念都有可视化辅助
- **4** 关键概念有配图
- **3** 有部分图表但不充分
- **2** 几乎无可视化，纯文字
- **1** 没有可视化或图示错误

## 7. interaction 互动性（**v2.4 权重 0.06**）

### 总分锚点

- **5** 丰富互动：表单、滑块、canvas、思考题、Quiz 兼具
- **4** 有多种互动形式
- **3** 有 1~2 种基础互动（按钮、表单）
- **2** 仅展示型，无互动
- **1** 完全静态

### 4 子项评分锚点

详见 `references/interaction_robustness.md`。

```
interaction_score = mean(4 子项) × 0.7 + llm_overall × 0.3
```

4 子项：

- **answer_tolerance**（答案接受度）：多选/范围/LLM 评分=5，严格精确=1
- **hint_progression**（渐进提示）：多级自适应=5，无提示=1
- **stuck_detection**（卡顿检测）：超时+重试+跳过+求助=5，全无=1
- **error_feedback**（错误反馈）：具体诊断=5，"再想想"=1

## 8. a11y 可访问性

- **5** 完美：语义化 HTML、ARIA 标签、键盘可达、对比度达标
- **4** 大部分 ARIA 正确，少量遗漏
- **3** 部分 ARIA 或语义化
- **2** 几乎无 a11y 考虑
- **1** 完全没有

## 9. learnability 可学性（**v2.4 新增，权重 0.15**）

衡量**普通学生能否独立看懂/做对**，不看设计专业度，看真实学习体验。

- **5** 看一遍就懂，操作链顺畅（≤ 3 步）
- **4** 大部分能懂，少量卡顿（30 秒内能解决）
- **3** 需要反复看才能懂，操作链有跳跃（4~5 步）
- **2** 概念跳跃大，普通学生跟不上
- **1** 即使认真读也难懂

### 3 子项

- **concept_jumps**（概念跳跃）：5=每个新概念前都有"回想上一节"，1=大量术语无解释
- **operation_chain_length**（操作链长度）：5=核心任务 ≤ 3 步，1= > 5 步
- **back_navigation**（回头率）：5=breadcrumbs / 返回目录齐全，1=完全无导航

详见 `references/learnability_flow.md`。

## 10. flow 学习流（**v2.4 新增，权重 0.10**）

衡量**章节顺序、操作链流畅性、回头率**。

- **5** 从头到尾一气呵成，操作链 ≤ 3 步完成
- **4** 流畅但偶有小跳跃（1~2 处需要回查）
- **3** 章节顺序合理但操作链偏长（4~5 步）
- **2** 操作链 > 5 步，章节间过渡突兀
- **1** 顺序混乱，回头率高

### 2 子项

- **section_order**（章节顺序）：5=按学习曲线递增，1=顺序不合理
- **transition_quality**（过渡质量）：5=每章结尾有"接下来..." + 顶部进度条，1=完全无过渡

详见 `references/learnability_flow.md`。
